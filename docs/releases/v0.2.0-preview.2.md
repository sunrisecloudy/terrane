# Terrane v0.2.0 Preview 2

> **Unsigned preview:** This build is not signed with Apple Developer ID and
> is not notarized by Apple. macOS Gatekeeper will warn or block it. Install it
> only if you trust this repository and have verified the SHA-256 checksum.

Preview 2 substantially reduces the initial download. Non-core native
capabilities are published as individually signed release assets and fetched
from this exact release only when first used. Every downloaded archive must
match the hash pinned in the signed capability index before Terrane runs it.

This is an early-testing build for M-series Macs, not a production release.

## Included

- Native Apple-silicon Terrane app with the organic Terrane icon.
- Fourteen built-in local-first apps.
- Signed catalog for 42 on-demand native capability workers.
- Local-first storage, deterministic replay, native permissions, GUI-owned MCP
  attachment, local model support, and native app creation.

## Requirements

- An M-series Mac (`arm64`).
- macOS 13 Ventura or newer.
- Network access the first time a non-core capability is used.

Downloaded capabilities are cached under Terrane's local workspace. Terrane
does not resolve newer capability versions: it downloads only the archive and
SHA-256 digest pinned by this app build.

## Install

1. Download `Terrane-0.2.0-macos-arm64.dmg`, `SHA256SUMS`, and
   `release-manifest.json` from this pre-release.
2. In Terminal, verify the download:

   ```sh
   shasum -a 256 -c SHA256SUMS
   ```

3. Open the DMG and drag Terrane to Applications.
4. In Finder, Control-click Terrane, choose **Open**, then confirm **Open**.
   If macOS still blocks it, use **System Settings → Privacy & Security →
   Open Anyway** after the blocked launch attempt.

Do not disable Gatekeeper globally.

## Verification boundary

The DMG is limited to 40 MiB by the release script. Publication verifies the
arm64 architecture, macOS 13 minimum, 14 apps, signed 42-entry capability
index, all 42 external archive hashes and worker architectures, icon assets,
exact source commit, and checksum integrity. The DMG and all capability
archives are downloaded from GitHub and checked again after publication.

These checks do not provide Apple identity, notarization, malware scanning, or
Gatekeeper trust.

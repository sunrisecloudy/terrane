# Terrane v0.2.0

Terrane v0.2.0 is the first production-oriented release of the rebuilt
local-first Terrane desktop host.

## Included

- Native Apple-silicon macOS application with the Terrane app catalog.
- Fourteen built-in personal apps, including App Builder, Chat, Control Room,
  Password Manager, Photobooth, Pixel Paint, Scribe, Todo, and Tomorrow.
- Forty-two independently packaged native capability workers with a signed
  capability index and exact-version repair support.
- Local-first event log, deterministic replay, native permission broker, MCP
  attachment to the running GUI, local model support, and app source editing.
- New Terrane application icon and Finder-ready DMG installation.

## Requirements

- An M-series Mac (`arm64`).
- macOS 13 Ventura or newer.
- Approximately 4 GB of free space is recommended for local models and build
  caches; the base application requires substantially less.

Intel Macs are not supported by this release.

## Install

1. Download `Terrane-0.2.0-macos-arm64.dmg`.
2. Verify its SHA-256 value against `SHA256SUMS`.
3. Open the DMG and drag Terrane to Applications.
4. Open Terrane from Applications.

The application and DMG are signed with Apple Developer ID and notarized by
Apple. Gatekeeper should open Terrane without a security override.

## Data and network behavior

Terrane stores its workspace locally under `~/.terrane`. Capabilities that use
external model providers, websites, network services, or MCP servers make
connections only when configured and invoked. See `PRIVACY.md` and the
in-application Control Room for the product boundary.

## Verification

The release includes:

- `SHA256SUMS`;
- `release-manifest.json` with source commit, platform, architecture,
  capability signing key, and artifact digest.

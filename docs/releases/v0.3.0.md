# Terrane v0.3.0

Terrane v0.3.0 is the recommended local-first desktop release for Apple
silicon Macs.

## Highlights

- Native, explicitly opt-in Premium authentication and sync boundaries.
- A new Health experience for meals, nutrition, history, calendar, and
  insights.
- A new Spending app for local invoice and expense organization.
- Native photo selection and the Visual Intake workflow.
- Refined app icons in the native macOS sidebar.
- The existing catalog of Todo, Chat, App Builder, Control Room, Photobooth,
  Scribe, Pixel Paint, Search Notes, OS Monitor, and other personal tools.

Local apps remain usable without an account or network connection.

## Requirements

- An M-series Mac (`arm64`).
- macOS 13 Ventura or newer.

Intel Macs are not supported by this release.

## Install

1. Download `Terrane-0.3.0-macos-arm64.dmg` and `SHA256SUMS`.
2. Verify the DMG's SHA-256 value against `SHA256SUMS`.
3. Open the DMG and drag Terrane to Applications.
4. Open Terrane from Applications.

The application and DMG are signed with Apple Developer ID, notarized by
Apple, and verified with Gatekeeper before publication.

## Accounts and privacy

Terrane starts in local mode. Premium sync is enabled only after an explicit
sign-in action, and native credentials are not exposed to generated apps, web
views, or app event logs.

The Developer ID build supports Google sign-in for Premium sync. Sign in with
Apple is not included because Apple does not support that entitlement for
Developer ID applications distributed outside the Mac App Store.

See `PRIVACY.md` and the in-application Control Room for the complete product
boundary.
